# APA 7 citation guide

Read when the user requests APA or the deliverable is clearly academic. Follow any more specific institutional instructions and check APA's current guidance for unusual source types. Verify bibliographic details in the work or an authoritative record; never invent missing details.

## In text

Use author and year: (Lee, 2020), Lee (2020), (Lee & Patel, 2020), or (Lee et al., 2020) for three or more authors. Use `&` inside parentheses and `and` in running text (`Lee and Patel (2020)`). For a group, use its name; define an abbreviation only when useful. Use (n.d.) if no date is available. Include a page, paragraph, or other locator for direct quotations; a locator for a paraphrase is optional and helpful for long or complex works. Quote sparingly and accurately.

When AI is used as a search aid, inspect and cite the underlying sources rather than citing the AI as the source of a fact.

For a sustained paraphrase, introduce the source clearly. APA advises against repeating its citation in every sentence when source and topic stay clear; cite again when the topic, source, or paragraph changes. Make clear where the source's ideas end and your own analysis begins. See [APA's in-text citation checklist](https://apastyle.apa.org/instructional-aids/in-text-citation-checklist.pdf).

If an original is unavailable and its claim is learned from another source, identify it as secondary: (Original Author, year, as cited in Consulted Author, year), and list only the work actually consulted. Avoid implying that you inspected the original.

## References

Include a References list with entries corresponding 1:1 to works cited in the text—verify every in-text citation has a matching reference entry (matching author spelling and year) and remove any uncited entries. Never backfill unseen co-authors, DOIs, or page numbers from memory when a snippet only shows `et al.`—inspect the actual PubMed/publisher record, or omit unverified fields and disclose summary-only access. Alphabetize by author; apply a hanging indent in documents. All authors in References use `Surname, I.` order (never `I. Surname` after the first author). General elements are author, date, title, and source. Use sentence case for article, book, and web page titles, and title case for journal names; for 21 or more authors, list the first 19, `. . .`, and the final author. Use the actual source category and its APA rules; when author and website name are the same, omit the duplicate site name. Give a DOI as a URL when available; do not add a period after a DOI or URL. Use a retrieval date only where appropriate for content designed to change and not archived. Consult [APA reference examples](https://apastyle.apa.org/style-grammar-guidelines/references/examples) for unusual cases.

## Finished example

APA Style (n.d.) explains that scholarly citations identify the contributions on which a writer builds. Its guidance covers both paraphrases and quotations.
